## Context

当前 FastAPI 的 `/` 返回 `app/static/index.html`，`app.js` 通过两个 API 渲染最新便签与月历。现有 CSS 为白底黑字、细线边框、1100px 居中布局，720px 以下单列。建设动机见 proposal.md。

## Goals / Non-Goals

**Goals:** 用两个明确路由和静态文档建立博客层级，支持直接访问、刷新和普通链接跳转；延续现有维护方式。

**Non-Goals:** 不增加文章系统、Markdown 渲染、后台、数据库、评论、搜索或新的前端构建流程；不代填个人履历，不执行远端发布。

## Decisions

### 两个路由、两个静态文档

`/` 返回 `index.html` 的 HTML 响应，`/now` 返回 `now.html` 的 HTML 响应。两页在请求时读取根目录 `signature.txt`，经 HTML 转义后插入页尾占位注释；不引入模板依赖或新的 API。公共 CSS 保持 `/static/style.css`；`app.js` 只在便签页加载，主页不需要 JavaScript。

采用普通链接而非单页前端路由，避免增加构建工具和刷新回退配置。两页手动维护短小导航，未来页数增多后再评估模板抽取。

### 主页仅保留现有栏目

站名为用户指定的 `EVARA'S BLOG`，站名与栏目文案直接编辑 HTML。主页仅有一个实际栏目，不包含大幅介绍区。桌面布局如下：

```text
// EVARA'S BLOG                      首页    正在做
──────────────────────────────────────────────────
01 / NOW
正在做                                         ↗
一些按日期留下的记录。看看最近在忙什么。
                                      查看正在做 →
──────────────────────────────────────────────────
[signature.txt 中的个性签名]
```

导航仅包含两个可用入口，当前页以下划线和 `aria-current="page"` 标识；站名链接回 `/`。主内容直接从“正在做”栏目开始，不留介绍区的空白高度。删除 `.home-intro` 及相关移动端规则，保留便签页仍使用的 `.intro-description`。栏目区保留下分隔线，上方利用站点头部已有分隔线，避免两条线紧贴。

### 视觉与移动端

保留现有字体栈、白底黑字与 `//` 标识。主页“正在做”作为一级标题，采用与原栏目标题一致的约 21–28px 字号，正文约 16px、行高 1.8，沿用 shell 宽度。页脚使用面向读者的文案。

720px 以下导航可换行、栏目单列，保留约 16px 左右页边距。链接提供 hover 和 focus-visible，装饰箭头对辅助技术隐藏。相比增加图片、动画或外部字体，这种设计更适合现有简洁站点。

### 便签页保留交互

在原“正在做”页面顶部添加公共导航，当前项为“正在做”。保留原日历、便签 DOM ID、定位与月份切换逻辑；浏览器标题为“正在做 · EVARA'S BLOG”。两个 API 与 `app/notes.py` 行为不变。

### 文件签名

固定内容源为根目录 `signature.txt`，按 UTF-8（兼容 BOM）读取，保留内部换行、去掉首尾空白。每次页面请求重新读取，响应设 `Cache-Control: no-store`，不需要额外脚本、API 或重启来更新签名。文本经 HTML 转义，CSS 使用 `white-space: pre-wrap` 和长词换行，替换两页原先整段页尾文案。缺失、空白、无法读取或编码无效时省略页尾，主要页面仍正常。

本地提供初始签名“慢慢写，慢慢更新。”与同内容的 `signature.example.txt`。实际 `signature.txt` 加入 Git 忽略，内容由使用者单独维护。后台变更首次生效需要重启旧服务，此后修改签名只需刷新。

### 应用验证

现有 unittest 增加两页路由、核心元素、导航链接、脚本隔离验证，继续回归原 API 筛选、排序与月份校验。浏览器检查两页往返、直接刷新 `/now`、日历与定位、375px 和桌面布局、键盘焦点、空内容和接口失败状态。

更新通用 README，说明页面与静态资源位置；应用测试不依赖本机交付工具。

## Risks / Trade-offs

- [根路径旧收藏变为博客主页] → 显眼的栏目入口和文档说明帮助访问 `/now`，不将主页重定向回栏目。
- [旧 daily-work-notes change 的“首页”仍指便签页] → 本 change 明确替换入口语义，保留旧规划历史，后续同步主规范时统一表述。
- [导航重复维护] → 两页同次修改和验收，页面增多后再抽取。
- [签名文件不可读] → 省略页尾，确保主要页面可访问；文档说明文件编码和位置。

## Migration Plan

1. 保留现有便签和用户工作区改动，新增主页、栏目页及路由。
2. 本地完成应用测试和视觉检查，更新通用文档。
3. 使用共享源码核验两页与 API。
4. 回滚使用上一版应用代码，不变更 `notes/`。不自动归档 change。

### 栏目页介绍移除

删除 now.html 的 page-intro 区域及无其他引用的相关 CSS，保持最近便签区域现有上边距、月历与文件签名。

### 圆润轻松字体

Quicksand 的 latin 400/500 woff2 与 OFL 许可证保存在项目静态资源目录，不依赖 Google Fonts。站名和英文正文使用 Quicksand，中文标题及签名使用 YouYuan（幼圆），中文正文使用 Microsoft YaHei，缺失中文字体时依次回退到 PingFang SC 和系统 sans-serif。导航保留正文样式，数字标识仍使用等宽字体。

### 字重与字号调整

增加本地 Quicksand 700 字体供站名及标题使用，幼圆中文标题允许合成粗体。最新便签固定 16px，历史便签 14px，保留文本自动换行与原行距。
### 月度便签翻页

在现有月度 API 返回数组上维护页索引，一条便签对应一页，不改后端数据结构。翻页按钮和页码放在纸张下方，纸张使用轻微阴影、角部折页与 3D 旋转，延续黑白风格。使用浏览器 Web Animations，前半段移出旧页，后半段显示新页；翻页期间禁用页按钮，通过版本标识和动画取消防止切月后旧内容覆盖。

日历点击和最新便签定位复用同一页选择函数，并更新日历按钮的当前标识。空月、加载、错误隐藏分页；每次切月重置第一页，保留旧月请求版本控制。长文本自然扩展高度，动画期间暂时维持高度避免跳动。使用 `prefers-reduced-motion` 时直接替换，不增加库。
