## Why

当前域名用于个人博客，但根路径只展示“正在做”，缺少个人站点的整体入口。先通过两个页面建立博客结构，继续使用现有技术栈和文件内容源，降低建设与维护成本。

## What Changes

- **BREAKING**：`/` 从便签主页改为博客主页，原便签页面迁至 `/now`；最新便签与月历功能均保留。
- 新主页采用黑白、细线与留白的风格，包含站点导航和唯一的“正在做”栏目入口；删除大幅介绍区及其专用样式。
- 两页均提供“首页 / 正在做”导航，当前页有明确标识，支持手机浏览与键盘操作。
- 字体采用用户选择的“圆润轻松”：本地 Quicksand、幼圆标题与签名、微软雅黑正文，中文字体缺失时使用系统回退。
- 日历旁的月度便签一条一页，提供页码、前后翻页和纸张翻转效果；日历日期与最新便签定位到对应页。
- 两页站名统一为 `EVARA'S BLOG`，页尾替换为根目录 `signature.txt` 的纯文本签名，每次请求读取，修改后刷新生效。
- 签名正文默认不进入 Git；保留 `signature.example.txt` 作为内容格式示例。
- 本期仅上线两个实际可访问的页面。文章、关于等栏目待有内容时再扩展，不添加空链接或虚构文章。
- 沿用 FastAPI、原生 HTML/CSS/JS、`notes/*.txt`，不增加数据库、前端框架、在线编辑或构建流程。

## Capabilities

### New Capabilities

- `blog-pages`：个人博客主页、独立“正在做”页面与跨页导航，以及便签页面迁移后的行为兼容。

### Modified Capabilities

无。`openspec/specs/` 当前没有已发布规范；旧 `daily-work-notes` change 将“首页”定义为便签页，本 change 显式提出替换该入口语义，实施时应保留旧 change 的历史记录。

## Impact

- `app/main.py`：根路径返回新主页，新增 `/now` 页面路由；现有便签 API 保持不变。
- `app/static/`：拆分主页和便签页 HTML，添加公共导航及主页样式，便签脚本仅在便签页加载。
- `tests/test_notes.py`：覆盖新页面路由、导航和原 API 行为。
- `README.md`：更新通用站点用途、页面路径和内容编辑方法。
- 不改变应用依赖和便签文件，不自动归档。
