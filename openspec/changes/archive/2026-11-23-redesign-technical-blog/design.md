## Context

`/blog` 使用原生 HTML 及共享导航。参考页使用醒目的刊头、细线网格及可进入正文的条目。

## Decisions

- 标题采用与个人项目共享的纯文字标题样式，标题区省略副标题。目录采用淡蓝边线，正文通过原生锚点进入。
- 按用户提供的顺序展示《我的AI编程流程，被一次额度用尽打回原形》和《把数据结构当成给 AI 的 API》。目录引用正文片段，文章保留原题、段落和标点。
- 桌面两列，窄屏单列。链接保留键盘焦点，文章通过各自的 URL 片段直达，无需页面脚本。
- 技术博客从独立的 UTF-8 JSON 目录读取内容。数组顺序决定展示顺序，每条存储稳定的 slug、标题、摘要和纯文本段落，可用 appearance 保留卡片样式。请求时读取和校验文件，模板只保留页面结构，文本经 HTML 转义后输出。
- 保留 `/blog` 的原有片段地址，将旧静态页面地址重定向到 `/blog`。空目录显示空状态，无法读取或目录不合法时返回 503。

## Verification

验证目录、两个锚点、返回目录和站点导航，逐段对照原稿，并保存桌面及手机截图。
