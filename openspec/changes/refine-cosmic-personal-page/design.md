## Context

原版为原生 Canvas 投影的四星域深空，个人页四个静态文件独立于首页和正在做。原版与其他项目改动均未提交，不能用覆盖整个工作树的 Git 操作做回退。现有文案来自已授权的个人兴趣线索，仍按可编辑文本维护。

## Goals / Non-Goals

**Goals:** 以精确位置、调节速度、及时停止和更清晰内容提升完成度；保留原有空间路线和技术栈。

**Non-Goals:** 不新增框架、外部素材、音频播放或个人资料系统；不覆盖原有两页或私人内容，不自动提交、归档或远端发布。

3. 速度控制影响输入幅度与平滑抵达响应，观察灵敏度影响相机方向输入；Shift 将增量缩小。Escape 停止当前飞行，Ctrl/Meta/Alt 组合不拦截；Ctrl+滚轮保留浏览器行为。内容打开先 stop 再冻结，避免关闭后突然续飞。
4. 航程、路线、档案、工具栏采用清楚的标签和统一轻薄玻璃视觉，减少微小字与不一致间距。内容在同一 HTML 源里分为概览、工具、音乐，用标签和分段说明阅读；原生 dialog 提供焦点管理。
5. 文字环按测量的字宽分布，缓存排布并在本地字体加载后刷新。保留形体、深度和配色，减少过重光晕与粒子噪点；不以重新设计替换已经认可的整体效果。

## Risks / Trade-offs

- [精确航程与场景更新相互抢值] → 输入控件聚焦或拖动时冻结，手动定位取消旧目标，更新时避免重写正在编辑的控件。
- [新增工具影响手机布局] → 手机独立重排，设置放入弹窗，验证 320、390 像素和横屏。
- [字体测量增加绘图负担] → 缓存字形排布，沿用帧率上限与资源密度限制。

## Migration Plan

修改独立个人页资源，现有 `/me` 静态资源刷新生效；完成应用测试和浏览器验证，核对首页与正在做保持不变。
