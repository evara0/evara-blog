## Why

现有首页和“正在做”用克制的黑白线条呈现记录，缺少专门表达站主个性的空间。增加独立个人页，以大胆排版、异形构图和丰富动画形成鲜明的个人视觉表达。

## What Changes

- 新增 `/me` 个人页及三页互通的“个人”导航，首页和正在做仅新增导航链接，原有内容、样式及交互保持不变。
- 个人页改为全屏可探索的宇宙空间，融合梦境式深度、彩色星云、星场、漂浮几何物件与动态文字形体。文字组成环带、圆柱和螺旋，在不同深度流动。
- 支持拖动观察、滚轮或前后按钮沿纵深行进，穿过文字与物件。空间包含起点、构造、声音、未知四个相隔较远的星域，并提供航程、星域直达、键盘前后行进、暂停和返回起点。
- 支持暂停动画、系统减少动态效果、键盘操作和手机布局。无脚本时仍能阅读与导航。
- 沿用 EVARA 名称，以“一个仍在生成的宇宙”为视觉叙事，内容围绕已知的工具构造与音乐探索，保持可编辑且不虚构履历或成就。
- 同步应用测试和通用源码说明，不自动归档。

## Capabilities

### New Capabilities

- `personal-page`: 个人展示、独立视觉与动画、可访问交互及三页导航。

### Modified Capabilities

无。当前主规格为空，原有页面行为保持不变。

## Impact

个人页使用独立 `app/static/me.html`、`me.css`、`me.js` 与本地场景模块，保留已有 `/me` 路由和三页导航；不再修改原有两页。同步通用 README 和应用回归测试。无需新增运行依赖、数据库或外部服务。
