## Context

保留 FastAPI、原生前端与已有 `/me` 路由。原有两页不可修改，个人页独立资源与签名插入机制继续复用。用户选定梦境空间和动态文字形体，要求将场景改为宇宙；上一版分区排版已不符合视觉目标。

## Goals / Non-Goals

**Goals:** 构建全屏宇宙，以透视文字环、螺旋、漂浮物件和星云形成空间深度。空间物件与个人内容相关联，提供视角控制及完整键盘回退。

**Non-Goals:** 不更改首页与正在做，不加入外部 CDN、自动播放音频、资料数据库或完整游戏，不自动归档。

## Decisions

1. 原生 Canvas 2D 加三维透视投影绘制星场、文字环和几何物件。星云以预绘制彩色云层与粒子叠加形成，限制像素密度和粒子数量；相比引入 3D 引擎无需新增依赖，离线访问资源完整。
2. 全屏深空使用蓝、紫、洋红与青色辉光，多个前后星域以各自的动态文字雕塑和物件展开。多字体文字环带与螺旋产生前后遮挡、尺度和透明度变化；移除传统内容分区与贴纸。
3. 场景算法独立于 DOM 控制，便于验证投影、距离边界、环带连续性与暂停时间。个人内容保存在 HTML 中，通过原生 dialog 展开；移动 DOM 按钮对应场景物件，底部静态入口提供稳定键盘访问。
4. 拖动改变相机观察方向；滚轮和前后按钮沿纵深移动相机，触摸支持拖动与按钮行进，W/S 提供键盘前后行进。返回起点恢复位置和方向。指针取消清理状态；聚焦、悬停和模态打开时冻结自主流动与正在进行的抵达动画。
5. 单个 requestAnimationFrame 循环，暂停、减少动态效果和后台隐藏停止时间推进。主动控制仍重绘静止场景。静态 CSS 宇宙背景与 HTML 内容默认可读，绘图初始化成功才启用沉浸模式。
6. 保留本地 Quicksand 与系统衬线、等宽及中文字体，文字可编辑；不自动引入或播放音乐。原有签名在沉浸场景底边低调展示。
7. 从环绕单点的距离缩放改为世界坐标减去相机位置，再旋转到相机视角并投影。相机沿 0–6400 航程推进，星域位于约 0、1900、3800、5700 的不同纵深，近裁剪面剔除已穿过的物体。固定焦距建立真实的视差，避免把同一个形体重复放大伪装成前进。
8. 星场与散落字形覆盖整个纵深；星云作为分层世界空间云团投影。多个星域采用不同文字、配色与几何，提供道路式视觉引导和静态直达入口。附近物件才显示漂浮按钮，远处或视野外按钮隐藏，稳定内容入口仍可访问全部介绍。
9. 普通模式对目标航程平滑靠拢，暂停、减少动态效果时主动输入立即改变位置。暂停或后台时不推进飞行；返回起点取消待完成的抵达动画。航程和当前星域随位置更新，边界限制防止迷失在无内容的无限空场。

## Risks / Trade-offs

- [小屏空间与导航挤占] → 手机缩小文字形体、减少粒子，重排固定控件，验证 320 与 390 像素宽度。
- [动画资源占用或不适] → 像素密度上限、限制绘制数量、缓存星云层、暂停循环与减少动态效果。
- [Canvas 缺少语义或点击目标漂移] → 图形 aria-hidden，真实 DOM 按钮与静态入口，聚焦和模态展开时冻结物件；原生 dialog 管理焦点。
- [脚本或绘图能力不可用] → 默认静态宇宙与可阅读 HTML 内容，初始化成功后才隐藏回退内容。

## Migration Plan

替换个人页资源、新增本地场景模块。现有路由不改，刷新即生效。应用回归测试与浏览器检查通过后保留页面预览；无需数据迁移或后端重启。change 不自动归档。
