## Context

这是一个单用户、只读的便签站点。便签由服务器上的 `notes/YYYY-MM-DD.txt` 文件维护，页面不需要编辑功能或数据库。

## Goals / Non-Goals

**Goals:** 首页显示截至当天最近一条便签；按月浏览带便签的日期和内容；黑白线条界面。

**Non-Goals:** 用户登录、在线编辑、数据库、自动发布到服务器。

## Decisions

1. 使用 FastAPI 暴露 `/api/current` 和 `/api/notes?month=YYYY-MM`，并提供静态前端。读取时直接扫描 `notes/`，无需重启即可看到新便签。
2. 便签文件严格采用 `YYYY-MM-DD.txt`，以 UTF-8 编码；无效文件名不进入日历。当天的判断由服务器本地时区决定，日期计算使用进程运行环境的时区。
3. 首页使用最近一个日期不晚于今天的便签。没有便签时展示空状态；未来日期的文件不提前成为首页便签。
4. 月历展示某月所有日期及便签标记，旁边按日期倒序列出该月每条便签的全文。点击日期定位对应内容。
5. 用 `uv` 管理普通 Python 依赖。

## Risks / Trade-offs

- 便签数量增加时每次请求扫描目录；个人便签规模下足够简单。
- 服务端时区决定“今天”，运行环境的时区须与内容日期约定一致。
- 文件内容直接显示为文本，前端通过 DOM 文本节点渲染，避免把便签当作 HTML 执行。

## Verification

- API 测试覆盖空目录、日期命名、最近便签跨越空白日期、未来便签和月度过滤。
- 本地运行测试验证静态首页与 JSON 接口。
