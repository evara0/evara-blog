## Context

`/projects` 由 FastAPI 渲染静态 HTML，沿用共享站头、导航、字体和页尾。四个示例均可直接链接到本仓库已有页面，脚本和样式由项目页单独加载。

## Goals / Non-Goals

**Goals**

- 将视觉重点放在一组统一风格的原创海报上，以局部露出的卡片提示可横向浏览。
- 让鼠标、键盘和触屏均可阅读介绍并使用真实链接。

**Non-Goals**

- 项目数据管理、外部作品发布及其他页面改版。

## Decisions

- 在静态 HTML 中维护四张卡片及本地图片，链接采用 `/`、`/now`、`/me#footprints-heading` 及 `/records`。
- 由固定宽高比的海报按钮承载图像和介绍面板。鼠标移入、键盘焦点和点击触发可见状态，介绍和链接采用独立的操作目标。
- 以原生横向滚动容器支持触屏和触控板，并保留前后按钮。鼠标在卡片区域时，将可消费的垂直滚轮输入转换为水平位移。到达对应边界或画廊未溢出时，交还浏览器的垂直滚动。移除卡片吸附，支持连续的小幅滚轮位移和触屏拖动。
- 保留现有站头，项目页使用独立样式。过渡受减少动态效果设置控制。

## Risks / Trade-offs

- 海报未加载时仍需辨识链接和读取介绍。采用静态链接与图片底色，并在脚本不可用时提供可阅读的介绍。
- 窄屏卡宽需兼顾文字空间与下一张海报的露出。使用实际浏览器确认 375px 布局、触摸与键盘滚动后的可用性。
