# Spec Delta

## MODIFIED Requirements

### Requirement: 独立博客主页

系统 SHALL 在 `/` 提供博客主页，按日期倒序展示最多八篇已发布的 Markdown 技术文章的标题、摘要、日期和标签，包含站点名称、七项主导航及链接到 `/now` 的唯一“正在做”栏目入口。主页 SHALL 不展示“记录想法，也记录正在发生的事”的大幅介绍区、其副标题或 PERSONAL BLOG 标识。主页 SHALL 不展示完整便签日历，不依赖便签接口完成主要内容展示。系统 SHALL 不展示虚构文章或不可访问的栏目链接。

#### Scenario: 访问主页
- **WHEN** 用户直接打开 `/`
- **THEN** 主内容先展示至多八篇最新 Markdown 技术文章及其 `/blog/<slug>` 正文链接，然后展示正在做入口，没有大幅介绍区，也不包含完整便签日历

#### Scenario: 没有便签或接口失败
- **WHEN** 便签目录为空或便签接口不可用
- **THEN** 站点导航和栏目入口仍可用

#### Scenario: 没有文章
- **WHEN** 没有符合发布条件的文章
- **THEN** 主页显示空状态，正在做入口和导航仍可用
