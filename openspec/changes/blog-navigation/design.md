## Context

FastAPI 挂载静态目录；旧个人页同时通过 `/me` 和 `/static/me.html` 可访问。

## Goals / Non-Goals

**Goals:** 保持现有黑白视觉、签名与便签功能，提供可访问的响应式导航。

**Non-Goals:** 内容管理系统、虚构条目或发布部署。

## Decisions

新页面沿用静态 HTML 和现有样式；栏目使用独立路由。个人介绍沿用原有文案，时间线无可信日期时显示空状态。旧 HTML 移至非公开目录，静态别名使用 307 重定向；相比删除，便于恢复。`/me` 直接提供新个人页，避免重定向循环。

## Risks / Trade-offs

[静态导航重复] → 回归测试核对各页顺序及当前项。[历史宇宙规范与本次目标冲突] → delta 明确移除相关要求，旧源码保留。

## Migration Plan

部署应用时一起更新路由和静态文件；回滚整个变更即可恢复旧页面。
