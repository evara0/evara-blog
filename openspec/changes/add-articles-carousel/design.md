## Context

各栏目由 FastAPI 返回 HTML，主导航维护在页面标记中。文章使用独立页面模板和视觉样式，沿用七项导航的顺序和站内地址。

## Goals / Non-Goals

发布目录独立于技术博客和每日便签。采用单个 UTF-8 JSON 文件维护标题、摘要、封面、正文段落和固定链接。

## Decisions

- FastAPI 渲染目录与正文，同一份文章数据服务两个入口。关闭脚本时仍可通过静态目录打开正文。
- 桌面左侧以文字为圆心向四周放射文章标题，篇目较多时使用可滚动目录。右侧以前后图文组露出画面边缘，选中组在弧线中部平直展示。文章栏目使用全幅浅粉渐变、玫红强调色与细线标题框。标题、摘要与封面分别占据三列，整组保留开阔留白。图片使用原创封面。
- 原生脚本维护选中项和相邻位置，将标题、摘要、阅读链接与封面置于同一个旋转元素内。转盘内支持方向键与滚轮，轮外保留页面滚动。手机将图文组纵向排版，用横扫、按钮和目录选择文章。
- 本机脚本选择样例目录并挂载原创验收封面，绑定回环地址。应用的常规启动加载独立的正式目录。

## Risks / Trade-offs

- 长标题和摘要会增加详情高度，布局允许自然换行与扩展。
- 桌面只显示选中组及两个相邻组，手机只显示选中组。非选中组移出键盘和辅助技术的访问顺序。减少动态效果使用即时切换。
- 目录文件作为维护者输入，正文及文字字段按纯文本转义，封面使用同源静态路径。

## Migration Plan

保留 /records 汇总页并更新入口。旧 /records/notes 返回兼容重定向。正式目录初始为空，录入后刷新即可。
